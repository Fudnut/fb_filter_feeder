Home feed sorting

Opens the Facebook home page on the feed you choose instead of Facebook's algorithmic order. Picking another Feeds tab yourself is respected.

Custom word filters

Enter one word or phrase per line. Matches are case-insensitive and limited to visible author, story and link-preview text.

0 filters

The list remains in browser storage and is never included in exported diagnostics.

Activity post filters

Each rule matches Facebook's own generated activity-story wording (for example "is now friends with"), not your friends' own words, and stays off until you turn it on. Select Debug in the main popup before enabling one, then confirm the purple outline lands on the right posts.

AI content label

Matches Meta's own "AI info"/"AI content" disclosure text next to the post timestamp. Off by default and unverified against a live Facebook capture - select Debug in the main popup before enabling, then confirm the purple outline lands only on AI-labeled posts.

Suggested post subcategories

Fine-tune which kinds of Suggested content the "Filter Suggested posts" toggle in the main popup catches. All six are on by default, matching the previous all-or-nothing behavior.

Marketplace default listing age

Marketplace only sorts by newest listings once you manually pick a "Date listed" filter, every visit. This forces it by redirecting to the same URL with that filter already applied - Facebook encodes it as a URL parameter, confirmed on category and search results pages. Untested on the plain Marketplace browse root; if Facebook ignores the parameter there, this simply does nothing on that page rather than breaking it.

Deleted Friends alerts

Retained for compatibility review, but not active in this beta.

Validation required

Facebook can return a ranked or incomplete friend list. Treating a missing entry as an unfriending event would create false alerts. This option will be enabled only after stable IDs and complete-enough captures pass repeated-session testing.

Included in this beta

Ad and Sponsored, Suggested posts, Reels, Marketplace advertising, the Stories tray, right-sidebar Suggested Groups, right-sidebar Group chats, seven opt-in activity-post filters, six Suggested-post subcategory filters and custom word filtering.
